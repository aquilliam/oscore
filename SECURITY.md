# Security

Please report vulnerabilities privately through GitHub's
[security advisory form](https://github.com/aquilliam/oscore/security/advisories/new),
not in a public issue.

You should get a reply within five working days. A confirmed vulnerability is
fixed and disclosed within 90 days of the report, in a release published
together with a GitHub security advisory. The advisory credits you, unless you
would rather not be named.

Only the latest release gets security fixes.
